# Benchmark evidence status

An earlier comparison table gave specific latency, memory, FPS, binary-size, efficiency-score and star-count values without reproducible receipts. Those values have been removed from active documentation and are not valid performance evidence. The original document is preserved in the external snapshot listed in [Migration scope](MIGRATION-SCOPE.md).

Yolo UI performance claims require a pinned source revision, target hardware/OS, toolchain and release flags, named workload, raw samples, repetitions, and artifact hashes. This document makes no general claim of framework parity or superiority. See [Workspace consolidation](WORKSPACE-CONSOLIDATION.md) for ownership boundaries and qualification requirements.
