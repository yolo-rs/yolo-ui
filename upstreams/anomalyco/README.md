# AnomalyCo UI source fleet

This directory collects the UI, TUI, design, and UI-bearing application repositories discovered in AnomalyCo's public repository list. Each source is a shallow Git submodule pointing to its `yolo-rs` fork; the corresponding upstream is retained in the fork's GitHub network.

| Area | Repositories |
| --- | --- |
| Native and terminal UI frameworks | [rune](https://github.com/yolo-rs/rune) ([upstream](https://github.com/anomalyco/rune)), [opentui](https://github.com/yolo-rs/opentui) ([upstream](https://github.com/anomalyco/opentui)), [textjs](https://github.com/yolo-rs/textjs) ([upstream](https://github.com/anomalyco/textjs)) |
| Typography, themes, brand, and design tools | [justice](https://github.com/yolo-rs/justice) ([upstream](https://github.com/anomalyco/justice)), [oc-plugin-rainbow](https://github.com/yolo-rs/oc-plugin-rainbow) ([upstream](https://github.com/anomalyco/oc-plugin-rainbow)), [opentui-index](https://github.com/yolo-rs/opentui-index) ([upstream](https://github.com/anomalyco/opentui-index)), [identity](https://github.com/yolo-rs/identity) ([upstream](https://github.com/anomalyco/identity)), [social-cards](https://github.com/yolo-rs/social-cards) ([upstream](https://github.com/anomalyco/social-cards)) |
| Terminal, editor, and browser UI | [opencode](https://github.com/yolo-rs/opencode) ([upstream](https://github.com/anomalyco/opencode)), [opencode-beta](https://github.com/yolo-rs/opencode-beta) ([upstream](https://github.com/anomalyco/opencode-beta)), [opencode-zed-extension](https://github.com/yolo-rs/opencode-zed-extension) ([upstream](https://github.com/anomalyco/opencode-zed-extension)), [terminal-control](https://github.com/yolo-rs/terminal-control) ([upstream](https://github.com/anomalyco/terminal-control)), [ghostty-web](https://github.com/yolo-rs/ghostty-web) ([upstream](https://github.com/anomalyco/ghostty-web)), [zed-extensions](https://github.com/yolo-rs/zed-extensions) ([upstream](https://github.com/anomalyco/zed-extensions)), [rift](https://github.com/yolo-rs/rift) ([upstream](https://github.com/anomalyco/rift)) |
| Native desktop and system UI | [hokum](https://github.com/yolo-rs/hokum) ([upstream](https://github.com/anomalyco/hokum)), [hokum-bluetooth](https://github.com/yolo-rs/hokum-bluetooth) ([upstream](https://github.com/anomalyco/hokum-bluetooth)), [hokum-sound](https://github.com/yolo-rs/hokum-sound) ([upstream](https://github.com/anomalyco/hokum-sound)), [clip](https://github.com/yolo-rs/clip) ([upstream](https://github.com/anomalyco/clip)), [flicks](https://github.com/yolo-rs/flicks) ([upstream](https://github.com/anomalyco/flicks)), [isocast](https://github.com/yolo-rs/isocast) ([upstream](https://github.com/anomalyco/isocast)), [hex](https://github.com/yolo-rs/hex) ([upstream](https://github.com/anomalyco/hex)) |

The pinned source revisions live in the root `.gitmodules` and Git index. These sources stay outside the Cargo workspace because they span Rust, TypeScript, and native application projects. `git submodule update --init --recursive upstreams/anomalyco` initializes them in a fresh checkout.
