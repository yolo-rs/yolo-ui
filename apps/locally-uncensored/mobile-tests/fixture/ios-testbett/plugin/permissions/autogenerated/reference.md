## Default Permission

Standardrechte des Harness-Plugins

#### This default permission set includes the following:

- `allow-simulate-memory-warning`
- `allow-lifecycle-log`
- `allow-back-gesture`
- `allow-registerListener`
- `allow-remove-listener`
